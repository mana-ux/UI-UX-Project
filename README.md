# Mediflow+

**Mediflow+** is a Hospital & Healthcare Management System developed as a **group project** for the **UI/UX Design module in the 3rd Semester** of the Higher Diploma in IT.

The system is designed to provide a user-friendly interface for managing hospital and healthcare-related activities and improving the overall user experience.

### Project Information

* **Project:** Mediflow+
* **Type:** Hospital & Healthcare Management System
* **Module:** UI/UX Design
* **Semester:** 3rd Semester
* **Project Type:** Group Project

### My Contribution

As a member of the team, I contributed to the project development and designed the **Entity Relationship (ER) Diagram** for the system and the SQL Part and did the presentation and explanation of the system
